🔧 REVISÃO DA OFICINA (QUESTÕES PARA APRENDER)

📘 MANUAL RÁPIDO: f(x) = ax + b

1. Valor Numérico f(k): Substitua x pelo número k.
Ex: Se f(x) = 3x - 2, então f(4) = 3·4 - 2 = 10.
2. Coeficiente Angular (a): Multiplica x e define a inclinação da reta.
Se a > 0: Crescente; se a < 0: Decrescente.
3. Coeficiente Linear (b): É o termo independente (sem x). Indica onde a reta corta o eixo y (quando x = 0).
4. Raiz ou Zero da Função: É o valor de x que faz f(x) = 0.
Ex: 2x - 8 = 0 ⇒ 2x = 8 ⇒ x = 4.
5. Regras de Aceleração Gearheads:
• Cada acerto sobe 1 marcha (M1 até M6) e dá impulso imediato.
• 3 acertos seguidos ativam o 🔥 TURBO!
• Errar trava as engrenagens por 1,2s e reduz uma marcha.
